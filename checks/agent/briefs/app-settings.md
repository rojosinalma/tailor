Use the HTML kit.

The settings of a small notes app. General: the name of the workspace, the time zone, the language.
Notifications: an email address for alerts, and switches for a daily summary and for mentions. Storage: how
many days to keep deleted notes (1 to 90) and the API token, hidden until I ask to see it, with a way to copy
it and to make a new one. At the end, a way to delete the workspace, which must ask me first.
Changes are saved as I make them, and I want to see that they were.

There is no server: stand in for it in the page's own script.
