# Architecture

## The three layers

| Layer | Files | Owns | Changed by |
|---|---|---|---|
| **core** | `core/tokens.css` `core/base.css` `core/layout.css` `core/tailor.js` `core/components.json` | the vocabulary: token names, class names, markup, aria states, layout geometry, behaviour | this repo only (contract) |
| **skin** | `skins/<id>/skin.css` + `manifest.json` | the *look* of every `t-*` class in one design system | a skin author, verified against tier-1 coverage |
| **palette** | `palettes/<id>.css` (generated from `palettes/src/<id>.json`) | the colour values of the `--t-*` tokens, dark and/or light | `bin/gen-palette` |

Looks are decoupled from markup: 8 skins × 21 palettes, every combination verified for coverage
and contrast, switchable with a two-line picker.

## Load order

tokens → base → layout → skin → palette → your `app.css` → `tailor.js`.

## Manifest

`manifest.json` (generated by `bin/build`) is the machine-readable index: vocabulary, skins,
palettes, the adopted icon sets and the skin × palette compatibility matrix. Together with `core/components.json` it
describes every component, skin and palette, so tooling and code generators can read the system
instead of guessing it.

## Repository

```
core/        tokens.css · base.css · layout.css · tailor.js · components.json (+ schema) · conventions.md
skins/       SKIN-CONTRACT.md · manifest.schema.json · _template/ · <id>/ (skin.css + manifest.json + README.md)
palettes/    src/<id>.json + palette.schema.json (canonical) · <id>.css (generated, do not edit)
icons/       package.json (pinned @iconify-json/* packages) · sets.json (adopted sets) — data only, read at build time
react/       tailor-react: Ui.* components + adapters/primer/ (+ themes/<mode>_<id>.css, generated) + bin/check-parity
showcase/    index.html + icons.svg (generated) · showcase.css · showcase.js
bin/         build · verify · gen-palette · gen-primer-theme · tailor (CLI) · lib/
docs/        SDD.md · architecture.md · usage.md · cli.md · configuration.md · icons.md · palette-licenses.md
manifest.json  generated index (vocabulary × skins × palettes × icon sets × compatibility)
```
