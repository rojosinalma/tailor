Button t-btn

⤢

The action control. One primary per view; secondary is the default look; danger/warning for their outcomes; ghost and link for quiet actions. xs is the compact toolbar/icon size.

Markup
<button class="t-btn" data-variant="primary">Save</button>
<button class="t-btn">Cancel</button>
<button class="t-btn" data-variant="ghost" data-tone="danger">Delete</button>
<button class="t-btn" data-icon="only" aria-label="Edit"><span class="t-icon">✎</span></button>

Loading = disabled + aria-busy, never a second click. No per-tone solid buttons beyond primary/danger/warning: colour is the outcome, not decoration.

Duration input t-duration

js:Tailor.duration⤢

Number + unit select (s / min / h); the stored value is always seconds in data-value. Never a bare seconds field.

Markup
<div class="t-input-group t-duration" data-setting="offline_after_s" data-value="900">
  <input class="t-input" type="number" min="0" step="1" id="offline" aria-label="Offline after">
  <select class="t-select" aria-label="unit"><option value="1">s</option><option value="60">min</option><option value="3600">h</option></select>
</div>

Tailor.duration.set(group, seconds) picks the largest unit dividing evenly; Tailor.duration.get(group) → seconds.
